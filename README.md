# 社会 フラッシュカード

社会の問題集をもとにしたフラッシュカードアプリです。
`index.html` 1ファイルで完結しています（外部ライブラリなし・オフライン動作）。

開くと時代を選ぶ画面が出ます。収録している時代：
- 飛鳥時代（p.18〜19）
- 奈良時代（p.24〜25）

時代を追加するときは `index.html` の `ERAS` に1ブロック足します。

## 使い方
- 単元を選ぶ → カードをタップして答えを確認 → 「覚えた」「まだ」で自己採点
- 終わったら「まだ」のカードだけをくり返し練習できます
- 「答え→問題」モードで逆向きの練習もできます
- 覚えた記録はブラウザに保存されます
